如何控制真實的電腦？

為了安全性，網頁瀏覽器無法直接控制您的真實鍵盤與滑鼠。要啟用「PC 實機運行」功能，請按照以下步驟操作：

  1. 確認您的電腦上已安裝 Python 3。
  2. 在終端機（CMD 或 PowerShell）安裝必要的控制庫： 
    pip install pyautogui flask flask-cors pynput
  3. 執行專案目錄下的連線輔助程式： 
    python local_runner.py
  4. 執行後，網頁將自動偵測並連線。當右上角狀態顯示為 ● PC 控制器已連線 時，即可點擊「PC 實機運行」！

⚠️ 安全提示：請注意實機運行會真正移動您的滑鼠與輸入文字。如果程式失控，可將滑鼠快速移到螢幕的四個角落之一，這會觸發 PyAutoGUI 的安全終止機制（Fail-safe）強制關閉執行！
